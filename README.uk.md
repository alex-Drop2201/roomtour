# ROOMTOUR

**Покрокові тури справжніми скриншотами будь-якого інтерфейсу.** Ти кажеш Claude, що пояснити: GitHub, пошту, продукт клієнта, запущений у тебе на комп’ютері. Натомість отримуєш локальну сторінку, де камера по черзі наїжджає на кожну зону, притемнює решту й пояснює зону простими словами. Кожна зона позначена категорією, яку ти обираєш під задачу, тож ще до кліку знаєш, що він зробить.

## Швидкий старт

Потрібні Claude Code і [Node.js 18+](https://nodejs.org). У терміналі:

```bash
claude plugin marketplace add alex-Drop2201/roomtour
claude plugin install roomtour@roomtour
```

Перезапусти Claude Code і набери `/roomtour` у будь-якому проєкті. Короткий онбординг налаштує все під тебе й одразу перейде до першого туру.

## Що ти отримуєш

- **Справжній екран, зона за зоною.** Жодних схем: живий інтерфейс, наближений до кожної зони, решта притемнена.
- **Прості слова на твоєму рівні.** Як дитині, як новачку або як колезі; рівень обираєш на початку кожного туру.
- **Твої власні категорії.** Для GitHub це може бути «можна дивитися / побачать інші / не чіпати самому», для пошти — «читання / впорядкування / надсилає або видаляє». Claude пропонує, ти вирішуєш. У кожної категорії свій колір, іконка й тип рамки, тож її видно і без кольору.
- **Факти, а не здогадки.** Для свого продукту дай Claude теку з кодом, і він перевірить у коді, що робить кожна кнопка.
- **Приватність за замовчуванням.** Скриншоти лишаються на твоєму комп’ютері, особисті дані можна розмити, а Claude ніколи не натискає те, що змінює дані.
- **Українська та англійська** одразу (і російська), на Mac і Windows.

## Спершу подивись демо

Демо — тур сторінкою публічного репозиторію на GitHub, англійською та українською. Склонуй цей репозиторій і запусти сервер:

```bash
git clone https://github.com/alex-Drop2201/roomtour.git
cd roomtour
node plugins/roomtour/skills/roomtour/scripts/serve.mjs .
```

Потім відкрий адресу, яку він покаже (зазвичай `http://127.0.0.1:8770/`), і додай `examples/github-repo/index.uk.html` для української або `examples/github-repo/` для англійської. Chrome і Edge можуть відкрити `examples/github-repo/index.uk.html` і напряму.

## Що потрібно

- **Claude Code** — вкладка Code у застосунку Claude або `claude` у терміналі.
- **Node.js 18 або новіший** — для скриптів, які створюють, перевіряють і показують тури. Версію LTS бери на nodejs.org.
- **Радимо: Playwright** — для чітких скриншотів будь-якого розміру. Один раз у терміналі:

  ```bash
  claude mcp add --scope user playwright -- npx @playwright/mcp@latest
  ```

  Без нього ROOMTOUR користується вбудованим браузером застосунку (чітко до приблизно 800 px завширшки) або скриншотами, які ти надішлеш.
- **За бажанням:** скил [Impeccable](https://github.com/pbakaus/impeccable) для дизайн-перевірки кожного туру та ffmpeg для склеювання й розмиття зображень. ROOMTOUR працює й без них.

## Встановлення

У терміналі (Mac або Windows), один раз:

```bash
claude plugin marketplace add alex-Drop2201/roomtour
claude plugin install roomtour@roomtour
```

Потім перезапусти Claude Code. Плагін, встановлений із термінала, з’являється й у вкладці Code застосунку.

У застосунку встановлені плагіни видно за кнопкою **+** біля поля вводу → **Add plugins**.

## Перший запуск: онбординг

Набери `/roomtour` (або `/roomtour:roomtour`) чи просто напиши «зроби тур …». Першого разу ROOMTOUR поставить чотири питання: мова турів, як пояснювати, де зберігати тури, яким браузером знімати. Він запам’ятає відповіді й одразу перейде до першого туру. Щоб потім змінити налаштування, скажи «roomtour: налаштування».

## Як зробити тур

1. Скажи, що показати: посилання, локальну адресу на кшталт `http://localhost:3000`, скриншоти або свій продукт разом із текою коду.
2. Дай відповідь на один раунд питань: яку частину, рівень пояснення та категорії для цієї задачі (Claude запропонує 2–4, ти перейменуєш, додаси чи прибереш).
3. Якщо сайт потребує входу, увійди сам у вікні браузера, яке відкриє Claude. Claude ніколи не вводить паролі.
4. Claude зніме екрани, напише кроки, перевірить тур і відкриє його.

Тури зберігаються в теці турів, кожен у своїй теці. Щоб відкрити тур пізніше, попроси Claude «відкрий тур …» або запусти скрипт serve на теці турів і відкрий адресу, яку він покаже.

## Приватність

- Claude лише дивиться: він ніколи не натискає те, що зберігає, надсилає, видаляє, погоджує чи змінює налаштування на сайті, який ти розбираєш.
- Скриншоти приватних екранів чи екранів після входу лишаються на твоєму комп’ютері; тека `shots/` кожного туру не потрапляє в git.
- Імена, пошту, обличчя та інші особисті дані на скриншотах можна розмити.
- Нічого не завантажується й не публікується, якщо ти не попросиш саме про цей тур.

## Оновлення та видалення

```bash
claude plugin marketplace update roomtour
claude plugin update roomtour@roomtour
```

Щоб оновлення спрацювало, перезапусти Claude Code. Налаштування й тури лишаються. Видалити: `claude plugin uninstall roomtour@roomtour`.

## Якщо щось не так

- **«Скриншоти не завантажилися»** — сторінку відкрито як файл у браузері, що не пускає сусідні файли (вбудований браузер Claude так робить). Відкрий тур через скрипт serve або в Chrome чи Edge.
- **Розмиті скриншоти** — вбудований браузер був ширший за приблизно 800 px. Встанови Playwright або попроси Claude знімати на 800 px.
- **Вікно Playwright без входу в акаунт** — це окремий браузер. Увійди там один раз, коли Claude попросить.
- **`node` не знайдено** — встанови Node.js LTS і перезапусти Claude Code.
