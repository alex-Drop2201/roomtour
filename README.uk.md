# ROOMTOUR

**Покрокові тури справжніми скриншотами будь-якого інтерфейсу.** Скажи Claude, що пояснити: GitHub, пошту чи свій продукт, запущений на твоєму комп’ютері. Ти отримаєш локальну сторінку. Камера по черзі наближається до кожної зони й притемнює решту. Панель пояснює зону простими словами. Кожна зона має категорію, яку ти обираєш для цієї задачі, тож ще до кліку знаєш, що він зробить.

[In English → README.md](README.md)

## Швидкий старт

Потрібні Claude Code і [Node.js 18+](https://nodejs.org). У терміналі (Mac або Windows), один раз:

```bash
claude plugin marketplace add alex-Drop2201/roomtour
claude plugin install roomtour@roomtour
```

Перезапусти Claude Code. Плагін, встановлений із термінала, з’являється й у вкладці Code застосунку: його видно за кнопкою **+** біля поля введення → **Add plugins**.

Набери `/roomtour` з посиланням або напиши «зроби тур …». Claude спершу відкриє сайт. Якщо там потрібен вхід, увійди власноруч у браузері, який покаже Claude. Далі один раунд, до чотирьох питань: мова (лише першого разу), яку частину показати, як пояснювати і які категорії. Потім Claude працює без твоєї участі й відкриває готовий тур.

Показати можна посилання, локальну адресу на кшталт `http://localhost:3000`, скриншоти, які ти надішлеш, або свій продукт разом із текою коду. Після першого раунду Claude запам’ятає мову й рівень пояснення, а теку турів налаштує для тебе. Щоб змінити налаштування, скажи «roomtour: налаштування».

## Що ти отримуєш

- **Справжній екран, зона за зоною.** Жодних схем: живий інтерфейс, наближений до кожної зони, решта притемнена.
- **Прості слова на твоєму рівні.** Як дитині, як новачку або як колезі. Рівень обираєш на початку кожного туру.
- **Твої власні категорії.** Для GitHub це може бути «можна дивитися / побачать інші / спершу спитати», для пошти — «читання / впорядкування / надсилає або видаляє». Claude пропонує, ти вирішуєш. У кожної категорії своя іконка, рамка й колір, тож її видно і без кольору.
- **Перевірене або позначене.** Кожне твердження взято з екрана, документації чи коду продукту або позначено словом «імовірно». Дай Claude теку з кодом, і він перевірить, що робить кожна кнопка.
- **Приватно від самого початку.** Скриншоти лишаються на твоєму комп’ютері. Особисті дані можна розмити. Claude ніколи не натискає те, що змінює дані.
- **Англійська, українська й російська** одразу, на Mac і Windows.

## Відкрити тур знову

Кожен тур лежить в окремій теці всередині теки турів (типово `~/Documents/roomtour`). Попроси Claude «відкрий тур <назва>» або запусти сервер власноруч:

```bash
node "<тека турів>/_roomtour/serve.mjs" "<тека турів>"
```

Потім відкрий адресу, яку він покаже. Chrome і Edge можуть відкрити `index.html` туру й напряму.

## Спершу подивись демо

Демо — тур сторінкою публічного репозиторію на GitHub, англійською та українською. Склонуй цей репозиторій і запусти сервер:

```bash
git clone https://github.com/alex-Drop2201/roomtour.git
cd roomtour
node plugins/roomtour/skills/roomtour/scripts/serve.mjs .
```

Відкрий адресу, яку він покаже (зазвичай `http://127.0.0.1:8770/`), і додай `examples/github-repo/index.uk.html` для української або `examples/github-repo/` для англійської. Chrome і Edge можуть відкрити `examples/github-repo/index.uk.html` і напряму.

## Що потрібно

- **Claude Code** — вкладка Code у застосунку Claude або `claude` у терміналі.
- **Node.js 18 або новіший** — для скриптів, які створюють, перевіряють і показують тури. Версію LTS бери на nodejs.org.
- **Сайти з входом** Claude знімає у вбудованому браузері застосунку або у твоєму Chrome. Входиш власноруч. Вбудований браузер знімає чітко до приблизно 800 px завширшки.
- **За бажанням: Playwright — для чітких публічних сторінок і локальних застосунків будь-якої ширини.** Один раз у терміналі:

  ```bash
  claude mcp add --scope user playwright -- npx @playwright/mcp@latest
  ```

- **За бажанням:** скил [Impeccable](https://github.com/pbakaus/impeccable) для дизайн-перевірки турів, якими ти ділишся, та ffmpeg для склеювання й розмиття зображень. ROOMTOUR працює й без них.

## Приватність

- Claude лише дивиться: він ніколи не натискає те, що зберігає, надсилає, видаляє, погоджує чи змінює налаштування на сайті, який ти розбираєш.
- Скриншоти приватних екранів чи екранів після входу лишаються на твоєму комп’ютері. Тека `shots/` кожного туру не потрапляє в git.
- Імена, пошту, обличчя та інші особисті дані можна розмити на сторінці. PNG-файли зберігають оригінал, якщо Claude не розмиє і їх для туру, яким ти ділишся.
- Claude нічого не вивантажує в мережу й не публікує, якщо ти не попросиш саме про цей тур.

## Оновлення та видалення

```bash
claude plugin marketplace update roomtour
claude plugin update roomtour@roomtour
```

Щоб оновлення спрацювало, перезапусти Claude Code. Налаштування й тури лишаються. Видалити: `claude plugin uninstall roomtour@roomtour`.

## Якщо щось не так

- **Порожня сторінка або «Скриншоти не завантажилися»** — сторінку відкрито як файл у браузері, що не пускає сусідні файли. Вбудований браузер Claude так і робить. Відкрий тур через скрипт serve або в Chrome чи Edge.
- **Claude просить увійти, але вікна не видно** — Playwright зазвичай працює без вікна. Попроси Claude взяти вбудований браузер застосунку.
- **Розмиті скриншоти** — вбудований браузер був ширший за приблизно 800 px. Попроси Claude знімати на 800 px або встанови Playwright для публічних сторінок.
- **`node` не знайдено** — встанови Node.js LTS і перезапусти Claude Code.
